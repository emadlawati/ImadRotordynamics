About the model

ROSS finite-element model built from the OEM lateral analysis (SOA700000035 rev. 0). It uses all 123 shaft sub-elements, 27 added masses, speed-dependent DE/NDE sleeve-bearing coefficients with cross-coupling, and Childs annular-seal coefficients (K, k, C, c, M) for each seal condition. It matches the report's dry criticals (961/3775/7674 vs 955/3807/7612 rpm) and its damped modes at 2980 rpm (1671/2467/3971 cpm, ζ 0.54/0.76/0.72 for process fluid, new clearances).
Supports are rigid ground behind the oil film, so the readings are shaft displacements as seen by proximity probes. Impeller–volute forces are not in the report and not in the model. Responses add linearly, so several weights can be combined.
Angle conventions: probe and keyphasor angles are measured from top dead centre in the direction of rotation. Phase is lag. A weight angle measured against rotation from the keyphasor notch (notch lined up under the keyphasor probe) moves every phase lag by the same amount.
